# ✨ PixelBead 拼豆图纸工坊

把任意图片一键转成可照着摆珠子的**拼豆图纸**，也能从空白画板手绘。纯前端、零安装、移动端可用。

🌐 **在线体验**：https://sageautoman.github.io/pixel-bead-generator/

---

## 这是什么

拼豆（拼豆/咕卡/Perler beads）是把彩色塑料小豆子按图纸摆进格板、熨烫定型的手工。PixelBead 帮你把照片/插画自动转成图纸：每格一个色号、配齐行列坐标和用料清单，照着摆就行；也支持直接在画板上手绘像素画。

全部运算在浏览器本地完成，**图片不会上传到任何服务器**。

---

## 主要功能

### 🖼️ 图片转图纸
- 上传照片/插画，自动像素化，输出**写实**与 **Q 版**两种方案任选
- **整图完整铺入画板**：大图等比缩放铺满，不会只截中间一块
- **AI 自动抠图**（可选）：识别主体、移除背景；模型按需下载、浏览器缓存，二次使用直接载入，带真实下载进度
- 手动裁剪：上传后可自由框选要保留的区域

### 🎨 色板与上色
- **MARD 291 色**国内 2.6mm 迷你豆色卡（默认，色号齐全）
- CIE Lab 空间最近邻匹配，颜色还原更准
- 画笔 / 橡皮 / 填充桶 / 吸管取色
- 一键描边（黑 / 白 / 自定义色）
- **5 种豆子样式预览**：实心 / 空心（未熨）/ 毛巾烫（哑光）/ 细闪 / 粗闪

### 🅰️ 艺术字印章
- 13 套精选字体（粗黑、站酷系、毛笔楷书/草书/行书等中文艺术字 + 像素英文字体带 `EN` 徽章提示）
- Google Fonts 按需 subset 加载，输入即预览，秒出
- 字号档位（迷你 → 满版）、描边、任意位置盖章

### 🧰 编辑器
- **撤销 / 重做**：`Ctrl/Cmd+Z` 撤销、`Ctrl+Y` / `Ctrl+Shift+Z` 重做，最多 50 步
- **图层**：背景层 + 印章层分离，可独立显隐，印章不破坏底图
- **选区工具**：矩形选区 / 魔棒（同色连通），可移动 / 复制 / 水平翻转 / 垂直镜像
- 画板缩放 / 平移，多档缩放预设

### 📐 画板尺寸
- **52² / 78² / 104²** 三档（默认 52²，约 13.5 / 20 / 27cm）

### 💾 保存与导出
- **工程文件 `.pbg`**：保存/加载完整工程（含图层、艺术字可二次编辑），自动缩略图
- **草稿自动保存**：意外关闭页面不丢，重开提示恢复
- **PNG 导出**：当前画板 1:1 直出
- **打印 / 导出 PDF**：A4 自动分页，图纸页带行列坐标 + 每格色号编号，独立颜色对照表页（色号色块 + 用量统计）

### 📱 移动端
- 底部工具栏 + 抽屉式调色板 + 双指缩放，窄屏不溢出

## 部署

零依赖、零构建，整个应用就是**单个 `index.html`**。

- 直接双击 `index.html` 用浏览器打开即可使用
- 或托管到任意静态服务器：GitHub Pages（当前在用）/ Vercel / Netlify / Cloudflare Pages / nginx / Apache

```bash
# 本地预览
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 技术栈

- **纯 HTML + CSS + Canvas**，无框架、无构建步骤
- **像素化**：USM 锐化 + Sobel 边缘检测 + 边缘感知降采样 + Lab 空间 K-means 颜色量化
- **AI 抠图**：`@imgly/background-removal`（small 模型，WASM，浏览器本地推理）+ alpha-aware 降采样（透明背景不误判成白豆）
- **图片适配**：contain 等比缩放（整图铺入，透明留白经 alpha 判定为空格）
- **艺术字**：Google Fonts 动态 `&text=` 子集化（把 CJK 字体压到几 KB）
- **豆子样式**：mulberry32 PRNG + 全局烫纸/闪粉 overlay
- **工程文件**：`.pbg` = palette index + base64 (uint16) 压缩，58²≈7KB；图层与印章独立保存可二次编辑
